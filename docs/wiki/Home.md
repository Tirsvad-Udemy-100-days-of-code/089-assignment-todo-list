# Todo List

A Trello-style Kanban board in Python 3.13 with the standard library, SQLite and plain JavaScript, built as Day 89 of the 100 Days of Code bootcamp. Each build step has a screenshot and a page about what it taught.

## Steps

- [Step 1: Project foundation](Step-1-Foundation): the tooling, the layers and the first page.
- [Step 2: Domain and storage](Step-2-Domain-Storage): the board rules, SQLite and the board page.
- [Step 3: JSON API and editing](Step-3-Api-Editing): the API, the router and the editing controls.
- [Step 4: Kanban board and drag and drop](Step-4-Kanban-Board): moving cards and lists.
- [Step 5: Card details](Step-5-Card-Details): label, description, due date, done and comments.
- [Step 6: Wrap-up and reflection](Step-6-Wrap-Up): the final checks and what we learned.

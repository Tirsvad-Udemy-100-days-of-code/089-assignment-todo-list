# Todo List

Papan Kanban gaya Trello dalam Python 3.13 dengan pustaka standard, SQLite dan JavaScript biasa, dibina sebagai hari ke-89 kursus 100 Days of Code. Setiap langkah pembinaan mempunyai tangkapan skrin dan satu halaman tentang apa yang dipelajari.

## Langkah

- [Langkah 1: Asas projek](Step-1-Foundation-ms): alat, lapisan dan halaman pertama.
- [Langkah 2: Domain dan storan](Step-2-Domain-Storage-ms): peraturan papan, SQLite dan halaman papan.
- [Langkah 3: API JSON dan penyuntingan](Step-3-Api-Editing-ms): API, penghala dan kawalan penyuntingan.
- [Langkah 4: Papan Kanban dan seret lepas](Step-4-Kanban-Board-ms): mengalih kad dan senarai.
- [Langkah 5: Butiran kad](Step-5-Card-Details-ms): label, huraian, tarikh akhir, selesai dan komen.
- [Langkah 6: Penutup dan refleksi](Step-6-Wrap-Up-ms): semakan akhir dan apa yang kita pelajari.
